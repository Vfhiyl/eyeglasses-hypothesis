# 眼镜假说可复现审计：开放历史数据能否支持「老花镜延长中世纪学者生涯」？

**类型：** 工作论文 / 预印本（审计报告）  
**版本：** v3.5（2026-07-23）  
**说明：** 本文自洽；正文不依赖仓库内其他 Markdown。复现代码与中间表可另附 GitHub 仓库（可选）。

## 摘要

Macfarlane 与 Martin 在 *Glass: A World History*（2002）及二手传播中，常将十三世纪凸透镜眼镜与欧洲知识增长相联系。本文关心的核心碰撞不是「眼镜能不能让人看清近处」（同义反复），而是：

1. **经验红利解锁说：** 学者越老越吃香；老花卡住经验峰值；眼镜让年长学者在人生最重要的后段继续做出革命性突破。  
2. **近距续工说：** 真出成绩多在年轻；眼镜补视力补不回脑力峰值，只是普通延长近距工时。

方法上整合 Studium、RETE/CDMV、ISTC、手稿序列、SDBM 多城导出、Wikidata 代表作年龄等开放数据，辅以 RCT 机制类比与 Ilardi/Jenks 贸易采用证据。

**三档裁决：**

| 档位 | 命题 | 裁决 | 主要依据 |
|------|------|------|----------|
| **A · 近距续工（弱机制）** | 老花后凸透镜降低近视觉读写边际成本；可让部分年长者继续干近距活 | **成立** | 现代 RCT 3/3；发明史（约 1286；Giordano 1306 布道）；原书 p.190 定性；伦敦/佛罗伦萨成罗贸易与低价显示大众化近距工具 |
| **B · 经验红利解锁（强窄命题）** | 眼镜系统性释放年长学者经验峰值产出（宏观可检：45+ 上升、玻璃中心优势、1290 断点强于印刷） | **拒绝** | Studium 45+ 份额无显著上升；Wikidata 代表作年龄（P800）出生≥1280 后**下降约 6–8 岁**（与「晚生涯解锁」相反）；玻璃中心人力资本常无优势或相反；1450 斜率变化强于 1290 |
| **C · 二手强断言** | 「文明起点就是眼镜」「延长智力生涯 +15 年」等 | **debunk** | 原书正文未检出「+15 年」逐字句（出自 Miller 书评压缩）；宏观数据不支持单一起点叙事 |

**一句话：** 现有证据偏向「普通延长近距工时」，不支持「年长经验红利被眼镜革命性解锁」。A 真、B 假、C 假并不矛盾。

**关键词：** 眼镜史；老花；知识革命；可复现审计；负结果；主张谱系

## 1. 引言

### 1.1 问题从何而来

Alan Macfarlane 与 Gerry Martin（2002）将玻璃——窗、镜、器皿、透镜、显微镜与望远镜——视为欧洲与其他文明分流的关键技术组合之一。其中，十三世纪意大利出现的**凸透镜老花镜**，在叙事上连接「约 40 岁 presbyopia 导致读写中断」与「知识工作者可工作年限延长」。Ilardi（2007）等眼镜史研究支持**发明时点与功能史**，但并不自动推出「职业生涯系统性延长」或「文明起点」。

中文互联网与英文书评层进一步压缩为量化口号（如「延长智力生涯 15 年」「不是蒸汽机而是眼镜」）。这些表述是否忠于原书、是否被开放历史数据支持，需要与**窄化检验命题**分开处理。

### 1.2 本文做什么、不做什么

| 范围 | 内容 | 本文 |
|------|------|------|
| **碰撞正题** | 经验红利解锁 vs 近距续工 | **主裁决对象**（见摘要三档表与第 7 节） |
| **宽命题** | 玻璃技术组合 → 科学革命 / 文明分流 | **未系统检验** |
| **可操作窄检验** | 45+ 宏观延长、玻璃中心优势、1290 vs 1450 | **用来拒绝「经验红利解锁」的强版** |
| **二手强断言** | 「文明起点」「+15 年」 | **谱系辨析 + debunk** |

**裁决规则（反模糊）：** 数据充分且预测落空 → 拒绝；充分且成立 → 接受；不充分 → 先补数据，不用悬空措辞硬判。本文对 B 的拒绝建立在充分样本（尤其 Wikidata 代表作年龄）之上，而非「证据不够所以不谈」。

本文定位：**可复现审计**——弱机制（近距续工）成立；强叙事（年长经验红利被眼镜解锁）在开放数据下拒绝。

## 2. 主张谱系（Claim Genealogy）

三层主张必须分开引用：

1. **原书宽论证：** 玻璃改变视觉与实验条件，与西方知识革命相关（Macfarlane & Martin 2002，约 p.60–61, 144–174, 184–203 等）。
2. **原书窄定性：** *spectacles lengthened the working life of individuals*（**p.190**）；*glasses in old age*（p.201）；Ch.8 老花 vs 东亚近视机制（p.148–151）。
3. **书评/二手量化：** *increased the intellectual life of professional workers by fifteen years or more*——见于 **John J. Miller 亚马逊书评**；作者在原书正文 p.1–203 及索引中**未检出逐字原句**。

**写作规范：** 引用 Macfarlane 时可用 p.190 定性句；**禁止**将「+15 年」标为已核原书页码，除非另引 Miller 书评并加注。

## 3. 理论链与识别缺口

```text
镜片制造 → 供应与价格 → 学者获得并佩戴 → 45+ 视力改善 → 继续读写讲授
    → 可观察活动跨度 → 知识产出 → 城市/欧洲长期增长
```

**关键缺口：** 「学者获得并实际佩戴」几乎无个体联立面板；本项目以**玻璃中心城市**、贸易量级与少数点名佩戴者作 proxy，识别较弱。现代 RCT 覆盖「视力改善 → 近工作成本」，外推至中世纪学术需强假设。

贸易形态可帮助区分叙事：若眼镜主要是「解锁少数巅峰学者」的稀缺杠杆，应偏小众奢侈；若早就是成罗进口、低价、多匠户产能，则更像**面向城市读写与工匠的大众近距工具**——支持档 A，削弱档 B 作为历史主引擎的说法。

## 4. 数据与方法

### 4.1 数据源（节选）

| 数据 | 用途 |
|------|------|
| Studium Parisiense API | 巴黎学者身份、生卒/活动年、45+ 占比与活动跨度 proxy |
| RETE / CDMV | 城市—世纪人力资本、活跃学者 |
| ISTC | 十五世纪印本城市横截面 |
| Buringh & van Zanden / OWID | 欧洲手稿分世纪序列 |
| 博洛尼亚 German Nation Acta | 1300 前后引用量比 |
| SDBM 多城导出（Place / Provenance） | 手稿产出 proxy；玻璃中心 vs 对照城 |
| Wikidata（P800 代表作 + P577 出版年；学者生卒） | 成就年龄分布；与佩戴证据对照 |
| WIAG / RAG / Stelter / Pantheon 等 | 主教/神职/名人 45+ 或任职跨度（部分样本小） |
| Ilardi / Jenks；Rosen 1956；Davidsohn | 采用、贸易、早期文献链 |
| PROSPER / PROSPER II / THRIVE | 现代老花 RCT，机制类比 |

原始抽取与哈希校验放在配套代码仓库的数据清单中；**阅读本文结论不依赖打开那些文件**。

### 4.2 检验设计

- **机制层：** RCT 三档效应（保守 / 中等 / 乐观），标注 experimental，任务不匹配中世纪学术。
- **职业延长：** Studium `share45` 比例检验（局部窗口 1200–1285 vs 1300–1385）；`observed_activity_span` 差分（**非**真实 career duration）；Wikidata 首/末代表作年龄（出生分割约 1280；局部窗与 1150–1550 稳健性）。
- **玻璃中心：** 城市活跃份额与 log 人力资本梯度；意大利子样本；ISTC 横截面比（**非** DiD）。
- **时点：** 趋势 Chow：`log(y) ~ t + post + t×post`，±80 年窗口；比较 1290 vs 1450 斜率变化；SDBM 局部窗后/前比。
- **稳健性：** 玻璃中心 leave-one-out、置换；Studium 人工样例审计；功效 / 最小可检测效应（MDE）。

### 4.3 证据标签

每行检验标注：

- **direction：** consistent / inconsistent / null（相对窄命题预测方向）
- **identification_strength：** experimental / associational / descriptive / sensitivity
- **supports_strong_causal_claim：** 恒为否（本流水线无预注册准实验设计）

## 5. 结果

### 5.1 子命题汇总

| 子命题 | 检验数 | 方向一致 | 方向不符 | 空/无关 | 数据不足占比 | **总裁决** |
|--------|--------|----------|----------|---------|--------------|------------|
| 近距续工机制（RCT） | 3 | 3 | 0 | 0 | 0% | **ACCEPT** |
| 大众采用 / 贸易量级 | 2 | 2 | 0 | 0 | 0% | **ACCEPT**（大众近距工具） |
| 45+ / 经验红利解锁 | 19 | 0 | 6 | 13 | ~37% | **REJECT**（充分样本方向相反或 null） |
| 玻璃中心知识优势 | 7 | 0 | 2 | 5 | 0% | **REJECT** |
| 1300 时点 vs 印刷 | 46 | 11 | 14 | 21 | ~15% | 时点可相容，但 **拒绝「眼镜断点强于印刷」** |

### 5.2 机制（现代 RCT）

三项 RCT 均方向一致、识别强度为 experimental。解读：老花矫正可提升现代情境下近距离工作效率约 **6%–33%**（因试验与假设档位而异），支持「**降低 45 岁后近视觉劳动边际成本**」；**不能**直接等同于中世纪抄写、讲授与经院阅读。

### 5.3 学者 45+、活动跨度与代表作年龄

- **Studium share45：** null（无显著上升）。  
- **Studium 活动跨度：** 显著缩短（测量/覆盖替代优先，但仍与「生涯延长」预测不符）。  
- **Pantheon / Wikidata 死亡年龄 45+：** 1300 后份额未升（Wikidata 显著下降）。  
- **Stelter HRE：** 几乎无 1300 前样本；在眼镜已扩散后的 1300s→1400s，**仍在 45 岁任职的占比无上升**（约 0.60→0.57，null）。  
- **Wikidata 代表作年龄（P800 + P577）：** 出生≥1280 相对 <1280，首/末代表作年龄均**显著下降约 6–8 岁**（n_pre≈234 / n_post≈1197；局部窗 1200–1360 同向）。经验红利解锁预测「后移」；数据为「前移」→ **与 B 预测相反，样本充分，可据此 REJECT**。  
- **稳健性：** 出生窗收窄到 1150–1550 仍约 −4.7 岁（p≈0.001）；玻璃中心出生地 vs 对照**无显著更晚**。  
- **Ilardi 贸易与订单（支持 A）：** 1462/1466 宫廷订单按年龄带/老花近用分级；佛罗伦萨 occhialai 名录显示商业产能，非「少数巅峰学者装置」。  
- **点名佩戴 × 代表作（旁证）：** Petrarch、Filelfo、Lotto 三人：有年代表作中约 **81% 在佩戴/订购证据之前**；平均代表作年龄比证据年龄早约 **12 岁**。方向支持 A、反对 B；**n=3 不足**，不单独改判。

### 5.4 玻璃中心与城市知识产出

- 活跃份额模型：玻璃中心系数约 +0.02，**不显著**（p≈0.87）。
- 人力资本梯度：系数显著**为负**（p≈0.02），与「玻璃中心领先」预测不一致——处理定义粗、混淆多，仅**削弱**窄命题。
- ISTC 十五世纪：玻璃 vs 对照城市印本量比约 21:1，p≈0.10，null；横截面，**非** DiD。

### 5.5 宏观时点：1290 vs 1450

- 人力资本序列趋势 Chow：1290、1450 窗口均显示斜率变化（描述性上与「1300 前后知识加速」可相容）。
- **1290 vs 1450：** 1450 斜率变化**更大** → inconsistent 于「眼镜断点强于印刷」。
- 手稿分世纪增长、博洛尼亚德侨引用等在 1300 前后描述性上升，与大学扩张、档案密度等多种替代解释并存。

### 5.6 SDBM 手稿（多城）

局部窗 = Manuscript Date 中点 ∈ [1200,1285) vs [1300,1385)；核心城要求前期 n≥30。约 11 个导出、~1.3 万条记录。

| 城 / 字段 | 后/前比 | 充分？ | 解读 |
|-----------|---------|--------|------|
| Venice Place / Provenance | **2.70 / 3.23** | 是 | 与「1300 后本地手稿增」描述一致 |
| Bologna Place（对照·大学城） | **3.14** | 是 | **同样上升** → 非玻璃中心特异 |
| Paris Place / Provenance | **0.55 / 0.91** | 是 | **不一致**于统一跳升 |
| Oxford Place | **0.29** | 是 | **不一致** |
| Milan / Nuremberg / Cologne / Florence 等 | 不等 | 前期过小或仅背景 | 不可与核心城同权 |
| 峰值半世纪 | 多为 **1450**（Oxford 约 1250） | — | 削弱「1290≫印刷」 |

**要点：** SDBM 填知识产出 proxy，**不能**识别佩戴。格局是「部分城升、部分城降、对照城也可升、峰值偏 1450」——与 timing 叙事可相容，但**拒绝**「眼镜制造中心在 1300 独有手稿跃迁」。

### 5.7 早期采用文献链（Rosen / Davidsohn）

- **伪条目：** 「1305 佛罗伦萨商人遗嘱」不见于 Rosen / Ilardi；系把 1305/06 定年、佛罗伦萨、1329 商人失窃案、1322 遗产清单体裁缝合而成。
- **发明定年（Rosen 1956 Part I）：** Giordano 于 Santa Maria Novella 布道（Florentine 1305-02-29 = 公历 **1306-02-23**）称「制眼镜之艺未满二十年」→ 发明约 **1286** 稍后；并称 *lettore*（即本人）曾见发明者。
- **早期文献（Rosen Part II p.204）：** 1316 带盒价；1322 佛罗伦萨主教镀银框清单；**1329** 商人诉失窃含 *unum par ochialium*（Davidsohn *Forschungen* III nr.955）。
- **更早商品化：** 威尼斯行会 1300/1301（*vitreos ab oculis ad legendum*）。

### 5.8 功效与敏感性

Studium share45 局部窗口下，检测约 **8–17 个百分点** 的占比上升需更大样本或更窄测量误差。反事实敏感性（统一发病年龄 + RCT 效应迁移）仅作 illustrative，**非**历史估计。

## 6. 讨论

### 6.1 与 Macfarlane / Ilardi 的关系

- **Ilardi / 发明史：** 1280 年代意大利眼镜——史料上 plausible，与「无大规模佩戴面板」不矛盾。
- **贸易量级（已核）：** 米兰宫廷 1462/1466 大额分龄订单；佛罗伦萨单价约 **0.67–3.7 soldi/副**；伦敦海关 1384–1509 成罗进口（单笔可上千至三千余副）；佛罗伦萨 1525 Catasto 回推少数匠户年产可达约 **4 万副** 量级。支持「扩散与近距劳动工具已成熟」；**仍不能**估计「学者因此多干了几年」。
- **Macfarlane 原书 p.190：** 「眼镜延长个人工作生涯」——定性支持故事方向，非回归系数。
- **Miller「+15 年」：** 不应当作原书可引用定理。
- **宽「玻璃文明」书：** 窄命题的 null / inconsistent **不能**用来证伪全书。

### 6.2 替代解释矩阵（摘要）

| 观测 | 眼镜叙事 | 常见更强替代 |
|------|----------|--------------|
| 1200–1300 手稿增 | 读写生涯延长 | 大学扩张、城市化、保存偏差 |
| 巴黎 Studium 1300 后记录暴增 | 学者活跃 | **覆盖规则与数据库 completeness** |
| 1450 断点更强 | 眼镜优先 | **印刷术、书价、识字** |
| 玻璃中心 HC 无优势 | 制造中心引领知识 | 城市编码噪声、金融/贸易/大学混淆 |

### 6.3 局限

1. **无学者级佩戴 × 职业跨度联立面板**；贸易与少数点名佩戴者仍不足以识别「多干了几年」。
2. Studium **observed_activity_span** 与真实 **career duration** 混淆；45+ 依赖生卒年解析质量。
3. ISTC「玻璃中心」为 **15 世纪横截面**，非 1300 准实验。
4. RCT 机制外推至七百年前的抄写文化。
5. 未检验望远镜/显微镜/实验器皿等 Macfarlane 宽链。

### 6.4 什么证据会改判？

| 新证据 | 可能改变 |
|--------|----------|
| 个体面板：佩戴者在 45+ 著作/任教/通信密度相对未佩戴者上升，且控制存活与职位 | **B** 可升为「部分 micro 支持」 |
| 成就年龄分布：新库显示 1300 后重大文本作者年龄中位数**显著后移**（当前 Wikidata 为前移） | **B** 需重审 |
| 仅有更多海关吨级数字、无晚生涯产出联系 | **不改变** A/B（只再确认大众工具属性） |

## 7. 结论

| 档位 | 命题 | 裁决 |
|------|------|------|
| **A** | 近距续工：老花镜降低近视觉边际成本 | **成立** |
| **B** | 经验红利解锁：年长峰值产出被眼镜系统性释放（宏观可检） | **拒绝** |
| **C** | 「文明起点」「+15 年」 | **debunk** |

1. **档 A：** 生理 + RCT + 发明史 + 大规模廉价贸易 → 眼镜是**普通近距劳动工具**，可延长年长者读写工时。  
2. **档 B：** 「越老越吃香 → 视力卡住 → 眼镜解锁革命性晚生涯」在开放宏观面板上**检不出**，代表作年龄甚至**前移**；也无充分佩戴×晚产出面板。  
3. **档 C：** 二手夸张，原书无「+15 年」逐字句。  

**定稿表述：**

> 眼镜假说有两种讲法：经验红利解锁，或近距续工。现有证据支持后者的弱版（老花镜确实降低近距读写成本，且很早就是大众货），拒绝前者的强版（开放数据看不出年长学者生涯被系统性延长；Wikidata 代表作年龄在眼镜扩散后下降而非上升）。「文明起点 / +15 年」是二手夸张。
